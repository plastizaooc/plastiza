# PLASTIZA — сайт

Статичний сайт без збірки: відкривається будь-яким вебсервером і деплоїться на Vercel / Netlify / GitHub Pages «як є».

## Структура

```
plastiza/
├── index.html            ← каркас сторінки, SEO-теги, підключення CSS/JS
├── css/
│   └── styles.css        ← усі стилі
├── js/
│   └── app.js            ← логіка: маршрути, сторінки, дані, форми, анімації
├── assets/
│   ├── img/
│   │   ├── products/     ← фото виробів (назва-варіант.webp)
│   │   ├── sections/     ← фото секцій (ТПА, будмайданчик, пресформа)
│   │   └── og-cover.jpg  ← прев'ю для соцмереж і месенджерів
│   └── icons/            ← favicon та іконки для телефонів
├── site.webmanifest      ← назва й іконки для «додати на головний екран»
├── robots.txt            ← дозвіл індексації + шлях до sitemap
├── sitemap.xml           ← карта сайту для Google
└── vercel.json           ← кешування й заголовки безпеки на Vercel
```

## Що де змінювати

| Що змінити | Де шукати |
|---|---|
| Телефони | `js/app.js` → `PH=[` |
| Email | `js/app.js` → пошук `plastiza.sale@gmail.com` |
| Адреси, графік роботи | `js/app.js` → `AD=[`, `HOURS=[` |
| Месенджери (посилання) | `js/app.js` → `MSGR=[` |
| Товари, розміри, ціни | `js/app.js` → масив товарів `P` |
| Фото товару | замінити файл у `assets/img/products/` з тією ж назвою |
| Статті блогу | `js/app.js` → `POSTS=[` |
| Питання й відповіді | `js/app.js` → `const FQ=` |
| SEO-тексти секцій | `js/app.js` → `SEOX` (ключі `home`, `about`, `catalog`, `delivery`, `svc0`–`svc2`) |
| Біжучий рядок | `js/app.js` → `TICK` |
| ЄДРПОУ | `js/app.js` → `EDRPOU` |
| Заголовок і опис для Google | `index.html` → `<title>`, `<meta name="description">` |
| Кольори, шрифти | `css/styles.css` → змінні `:root{…}` на початку файлу |

Тексти зберігаються парами `uk` / `en` — змінюйте обидві мови.

У `css/styles.css` правила, що стоять нижче, перекривають ті, що вище.

## Домен

У `index.html`, `robots.txt` і `sitemap.xml` вказано `https://plastiza-site.vercel.app`.
Якщо адреса інша або підключено власний домен, замініть її в цих трьох файлах.

## Що лишається зробити перед запуском

- **Форми.** Заявки зараз нікуди не надсилаються, лише виводяться в консоль браузера. Потрібно підключити сервіс прийому (Formspree, Web3Forms, Telegram-бот або вашу CRM) у функції `pushLead()` у `js/app.js`.
- **Реальні дані.** Перевірити ЄДРПОУ (зараз `00000000`), роки в історії компанії, кількість ТПА, тексти FAQ і SEO.
- **Обмеження SEO.** Сторінки перемикаються через `#` в адресі (`/#catalog`, `/#p-3`), тож Google бачить сайт як одну сторінку. Щоб кожен товар і кожна послуга індексувались окремо, сайт треба перевести на окремі адреси (`/catalog`, `/catalog/zirochka`). Це наступний етап (наприклад, на Astro або Next.js).
- **Зображення пресформи** на сторінці «Виготовлення пресформ» взято з інтернету. Для публічного сайту краще замінити його на власний рендер або фото.
